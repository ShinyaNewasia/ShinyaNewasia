# 我的小窝 · 使用说明

纯静态个人站 + 一个带登录的后台。没有外部依赖（不外链字体、不加载 CDN）。

- 网站：双击 `index.html`
- 后台：双击 `启动后台.bat`（推荐）或 `admin.html`
- 后台账号：**shinyanew** ，密码是给你的那一串

---

## 一、文件都是干什么的

```
我的小窝/
├─ index.html        首页
├─ m.html            手机版首页   ← 手机上看这个
├─ posts.html        全部文章（带标签筛选）
├─ post.html         单篇文章模板（内容看网址的 ?p=xxx）
├─ photos.html       照片墙（相册 + 灯箱）
├─ links.html        收藏夹 / 友链
├─ about.html        关于我
├─ admin.html        后台（要登录）  ← 导航栏那个「我的」
├─ server.js         可选的本地后台服务（真正的密码校验 + 写文件）
├─ 启动后台.bat       双击它就启动服务并打开后台
├─ assets/
│   ├─ style.css      全站样式：配色、圆角、动画都在开头的变量里
│   ├─ mobile.css     手机版样式
│   ├─ posts.js       所有文章的数据
│   ├─ site-data.js   站名、首页文字、侧栏、随手记、关于页、收藏夹
│   ├─ photos.js      照片墙的数据（相册和照片地址）
│   ├─ site.js        交互：主题切换、导航滑块、滚动进度、页面渲染、底部导航
│   ├─ mobile.js      手机版的渲染和主题切换
│   ├─ auth.js        后台登录（密码只存哈希）
│   ├─ admin.css      后台样式
│   ├─ admin.js       后台逻辑 + Markdown 转换
│   ├─ admin-photos.js 后台的「照片墙」面板（单独一个文件，跟 admin.js 互不打扰）
│   ├─ kit.css        后加的交互套件样式：搜索、目录、氛围特效、照片墙
│   ├─ kit.js         后加的交互套件：点击涟漪、搜索、目录、阅读增强、氛围特效
│   └─ gallery.js     照片墙页面的渲染（只有 photos.html 会加载）
└─ README.md
```

### 手机上看是什么样

- **导航栏那个「我的」**就是后台登录页（`admin.html`）。
- 手机上打开电脑版页面，**底部会自动出现一条导航栏**（首页 / 文章 / 照片 / 收藏 / 我的），顶部的文字导航自动收起，不会挤成一团。
- 想要更贴手机的样子，看 **`m.html`**：上面是头像和名字，中间四个大按钮（文章 / 照片 / 收藏 / 关于），下面是最近文章和随手记，底部是同一条导航栏。手机上可以直接把 `m.html` 加到桌面书签。
- 第一次用手机打开首页会冒出一句提示问你要不要看手机版；不理它 9 秒自己消失，点「×」就再也不问了。
- 电脑浏览器直接打开 `m.html` 也能看，会收成中间一条，方便检查手机效果。
- 手机上编辑后台有点挤（毕竟表单很多），**建议改内容还是用电脑**。

## 二、后台怎么用

### 进不去？先看这里

后台有两种运行方式，页面上会有一行小字告诉你现在是哪种：

| 方式 | 怎么进 | 说明 |
|---|---|---|
| **服务端模式**（推荐） | 双击 `启动后台.bat`，浏览器自动打开 `http://127.0.0.1:8787/admin.html` | 密码校验在服务端做，写文件也在服务端做。**别人拿到网页也改不动你的文件** |
| **本地文件模式** | 直接双击 `admin.html` | 密码是哈希比对的，但纯网页挡不住会改代码的人。写文件靠浏览器的文件接口，不行就下载 |

两种方式都要输账号密码。连着错 5 次会锁 30 秒。勾了「记住我」这台电脑 7 天内不用重输。

### 八个标签页

| 标签 | 能改什么 |
|---|---|
| 文章 | 写新文章、改标题/日期/网址名/标签/摘要/正文、删文章 |
| 标签 | 看所有用过的标签、改标签名（所有文章一起改）、删标签 |
| 照片墙 | 加相册、改相册名/日期/封面/简介、填照片（一行一张：`地址 \| 说明`）、传图 |
| 站点信息 | 站名、昵称、首页大标题和介绍段、首页小标签 |
| 侧栏 / 随手记 | 右边那三张卡、随手记 |
| 关于页 | 自我介绍、时间线、联系方式 |
| 收藏夹 | 分组和每一条收藏 |
| 保存 / 导出 | 把改动写回文件 |

**正文用 Markdown 写**，右边实时预览：

```
## 二级标题
普通段落，**加粗**，`行内代码`
- 列表
> 引用
三个反引号包起来是代码块
```

**改完必须点保存**：

- 服务端模式：点一下就写回 `assets/posts.js`，上一版自动存成 `posts.js.bak`
- 本地文件模式：第一次会弹出文件选择框，挑 `assets/posts.js`，**选一次之后就一直能直接写了**；万一浏览器不让写，会自动改成下载，你拖进 `assets` 覆盖即可

没保存就关页面也不怕：改动存在浏览器里，下次打开会问你要不要恢复。

## 三、关于安全（说实话版）

- **服务端模式**：密码在服务端比对，网页里没有密码；写文件只允许写 `assets/posts.js`、`assets/site-data.js` 和 `assets/photos.js` 这三个文件，别的路径一律拒绝；服务只监听 `127.0.0.1`，同一个 Wi-Fi 下的别人也访问不到；登录发的钥匙 12 小时过期，点「退出」立即作废。
- **本地文件模式**：密码以哈希形式存在 `assets/auth.js` 里，源码里看不到明文，但会改代码的人可以绕过登录界面。**如果这个后台要放到公网（比如 GitHub Pages），请务必用服务端模式，或者干脆不发 `admin.html`。**

### 改密码

1. 打开任意一个站点页面，按 F12，在 Console 里执行（把 `新密码` 换掉）：

```js
HUT_AUTH.sha256hex("hut::shinyanew::新密码")
```

2. 会得到一串 64 位的哈希，替换这两处：
   - `assets/auth.js` 里的 `PASS_HASH`
   - `server.js` 里的 `PASS_HASH`

两处必须一样。改完刷新页面，用新密码登录。

想换用户名的话，把 `hut::shinyanew::` 里的 `shinyanew` 也一起换，并且 `auth.js` / `server.js` 里的 `USER` 也要改成同样的。

## 四、手动改文件（不打开后台）

### 加一篇文章

打开 `assets/posts.js`，复制一整段 `{ ... },` 粘到数组开头，改掉这几项：

```js
{
  slug: "my-new-post",          // 网址里显示的名字，小写英文和横杠
  title: "文章标题",
  date: "2026-10-05",           // 必须 YYYY-MM-DD，列表自动按这个排序
  tags: ["学习", "随笔"],        // 中英文、多少 个都行
  excerpt: "列表里显示的一句话摘要。",
  body: `
    <p>正文。手改的话这里是 HTML，不是 Markdown。</p>
    <h2>小标题</h2>
    <pre><code>代码块</code></pre>
  `
}
```

### 在文章里放图片和视频

**用后台写**（推荐）：编辑器上面有「插入图片」「插入视频」两个按钮。

- 「插入图片」会弹出选文件，选好自动传到 `assets/uploads/`，并把 Markdown 插到光标位置
- 「插入视频」会让你填地址：本地的 mp4，或者 B 站 / YouTube 的链接都行
  （贴 B 站普通视频页地址就行，会自动换成正儿八经的播放器嵌入地址）

**Markdown 长这样**：

```
![图片说明](assets/uploads/xxx.jpg)

!video[视频说明](assets/uploads/demo.mp4)

!video[去 B 站看](https://www.bilibili.com/video/BV1xx411c7mD)
```

- 单独占一行的图片会变成带图注的图，**点一下能放大看**，按 Esc 或点空白处关掉
- `!video[...]()` 用来放视频：mp4 走播放器，B 站 / YouTube 自动换成 iframe 嵌入
- 行内的小图直接写 `![](地址)` 就行，不带说明就不显示图注

图片上限 3MB，太大的先去 TinyPNG 压一下。传上去的图都放在 `assets/uploads/`，
发布到网上时记得连这个文件夹一起传。

### 换头像

后台「站点信息」面板最上面。点「选一张图片」就能传，传完路径会自动填好；
不想传文件也可以直接贴一个图片地址（外链也行）。留空就用你名字的第一个字兜底。

### 改配色 / 动画

只改 `assets/style.css` 最上面那两个区块：

- `:root { ... }` —— 白天配色
- `html[data-theme="night"] { ... }` —— 夜间配色

主色 `--accent`（正紫 `#7C3AED`）、`--accent-2`（品红 `#C026D3`），背景 `--paper`，文字 `--ink`。

动画一共有这些：

**文字**
- 大标题**一个字一个字冒出来**（从下面浮上来、带一点旋转和模糊，一个字比一个字晚 30 毫秒）
- 标题里名字那块是紫色渐变，它只淡入、不位移——一 transform，渐变就会糊成一块灰
- 随手记前面的小圆点会**呼吸**
- 正文里的链接，鼠标移上去**下划线从中间往两边长**

**背景（电脑上才有）**
- 淡紫色的**网格**慢慢往上走，四周用遮罩化开
- 三团紫光慢慢飘，一束**斜光隔十几秒从左边扫过去**
- 一串小光点从下往上飘，飘到上面淡掉
- 一层很淡的**颗粒**，画面不那么"塑料"
- 鼠标一动，网格和光整层**轻轻偏一点**（视差）
- 外加一团**跟着光标跑的光晕**，鼠标移出窗口会淡掉

**进去 / 切换**
- 进页面时，标题 → 介绍 → 卡片 → 文章条目**依次上浮**
- **滚到哪儿哪才动**：还没进屏幕的内容先收着，滚到了才一屏一屏浮起来
  （有人一下把滚动条拖到底也不会卡住——滚过去的直接显示，另有 8 秒兜底全放出来）
- 顶部导航的紫色滑块会**跟着鼠标走**（扫过哪一项就滑到哪项，移开回到当前页），点下去还会往外"晕"一圈
- 往下滚动，顶部栏会**收窄一点并浮起来**
- 文章条目鼠标扫过时，左边会**冒出一条小横线**
- 侧栏卡片悬停会**轻轻歪一下**（跟着光标做小幅 3D 倾斜）
- 切换白天/黑夜是从按钮那里**圆形扩散**；换页面时正文**淡出 + 模糊**（顶部栏留在原地）
- 文章里的图**点一下能放大**（Esc 关掉）

**新加的几处小动静**
- 侧栏卡片：鼠标扫过时，一道柔光从左上往右下淌过去
- 标签按钮：鼠标移上去，紫色从下往上"灌"满，文字转白
- 顶部进度条前端有个亮点，像笔尖
- 头像外圈：一道渐变光环慢慢转
- 页首那行小字（INDEX · 宿州 · 2026）：字距从疏到密地收拢
- 二级标题下面那道线：滚到跟前才从左画出来
- 侧栏和关于页的链接：悬停时往右让一让
- 时间线：悬停时整行右移，日期同时变紫、字距松开
- 文章条目：鼠标扫过，日期变紫、标签边框跟着亮
- 小标签：悬停时浮起来发一点光
- 回到顶部按钮：鼠标压上去它就一跳一跳
- 站名：悬停时字距松开一点
- 页脚：整页安顿好之后才淡淡浮上来
- 上下篇导航：悬停抬一下
- 关于页的联系方式：邮箱和网址会**自动变成可点的链接**（"计应2604"这种既不是邮箱也不是网址的，保持纯文字）

**你的名字一直在变色**

- "ShinyaNew" 出现在三个地方——首页大标题、关于页的自我介绍、手机版页首——三处都是同一个效果
- 六个颜色的渐变在字上**缓缓流过**（紫 → 靛蓝 → 品红 → 粉 → 紫），7 秒一轮
- 同时整块色相还在紫的左右**慢慢摆动**（±30 度左右，11 秒一轮），所以颜色不是机械复读
- 想调快慢：搜 `assets/style.css` 里的 `name-flow`（7s，颜色流动）和 `name-hue`（11s，色相摆动）
- 想换颜色：改那两个选择器下面 `linear-gradient(...)` 里的色标

> 做渐变文字的坑：千万别给它加 `transform` 或把它拆成 `inline-block` 的单个字——那会让 `background-clip: text` 的裁剪失效，整块字糊成一个色块（这个坑真踩过，标题里那个名字就是这么修好的）

**正文是"写"出来的**

- 首页那段导语、关于页的自我介绍、文章正文里每一段，都是**从左往右一点点显现**——不是整块淡入，像有支笔在写
- 做法是遮罩擦除（`mask-size` 从 0% 走到 135%）。文字位置一点不动，所以不会晃、不会抖
- 一进页面就在眼前的那几段，会错开 100 毫秒依次开工；滚到下面才看到的段落，滚到了才开始写
- 时长改 `assets/style.css` 里的 `wipe-in`（现在是 1.6s）
- 段落交给这套之后，"上浮"那套就只管标题、图片、代码块了（选择器写的是 `.prose > *:not(p)`），不然一段文字会被两个效果同时折腾
- 有层保险：万一动画没跑起来，遮罩会停在 0%，字就永远看不见——所以代码会在 2.6 秒后自己把这个效果摘掉。宁可不要动画，也不能让文字消失

**性能上做的两件事**（动画一多最容易掉帧）
- 背景网格原来动的是「背景位置」，等于每一帧把整屏重画一遍；改成平移图层后只走合成
- 三团光斑去掉了多余的模糊滤镜——径向渐变本身就是软的，那层模糊纯属白烧显卡

**手机上**：粒子、颗粒、鼠标光晕这些会关掉（手指没有"悬停"这回事），只留网格和基本过渡。

**这些是每个页面都有的**：首页、文章列表、单篇文章、收藏夹、关于页——标题都会逐字出来，正文都会一段段滚出来，背景那一层也一样（没有哪一页是"素"的）。

动画的时长、缓动都在 `assets/style.css` 里，搜 `@keyframes` 和 `var(--ease)` 就能找到。

系统开了「减少动态效果」时，动画和那团鼠标光晕都会自动关掉；
手机（触摸屏）上不会生成鼠标光晕，底部导航栏的点击反馈照常。

## 五、后加的几件事（搜索 · 目录 · 氛围特效 · 照片墙）

这几样是从别人的一个博客项目（XinghuisamaBlogs，一个 Next.js + FastAPI 的站）里挑出来的，
重写成了不依赖任何框架的版本，配色全换成了小窝自己的紫色。
代码都在 `assets/kit.js` + `assets/kit.css` 里，每一节开头有编号注释，想删哪块删哪块。

### 全站搜索

- 按 **Ctrl + K** 唤起（Mac 上是 Cmd + K），或者直接敲 **`/`**，也可以点顶栏那个放大镜。
- 搜的范围是**标题、摘要、标签和正文**，命中处会黄色高亮，正文命中的会在下面带一句上下文。
- **↑↓** 选，**Enter** 打开，**Esc** 关掉。标题命中的排在前面，最多列 24 条。
- 手机上会自动变成整屏的搜索页。

### 文章目录

- 只有文章页有。右边那一栏会跟着你滚，当前在哪一节哪一节就亮起来。
- 点一下是平滑滑过去，顶部那条吸顶导航留了 88px 的余量，不会被盖住。
- 标题右侧悬停会冒出一个 `#`，点它会把锚点写进地址栏，方便发某一节的链接。
- 屏幕窄于 1080px 时目录收起来，变成右下角那个横线按钮，点开是从底部升上来的抽屉。
- 想调字号换行：`kit.css` 里搜 `.toc-list`。

### 阅读增强

- 文章标题下面的日期旁边多了一行「约 x 分钟 · y 字」（按每分钟 340 字估的，别太当真）。
- 代码块鼠标移上去，右上角浮出「复制」，点一下整块代码进剪贴板。手机上一直露着。
- 代码块如果标了语言（三个反引号后面写 python、js 这种），右上角会顺带显示出来。

### 点击涟漪

- 点页面任何地方，都从那儿散开一圈紫色的水纹，手机上也生效。
- 这是全站最费性能的一处，所以做了两件事：**有涟漪才启动动画循环，散完立刻停**；
  扩散速度按真实时间算，144Hz 的屏幕上不会比 60Hz 消失得更快。
- 不想要：`kit.js` 里搜 `① 点击涟漪`，把那一整块删掉。

### 氛围特效

- 顶栏那个圆形小按钮，点一下换一种：**关 → 樱花 → 下雪 → 萤火 → 小雨 → 关**。
- 选择记在浏览器里，**默认是关的**，不会自己冒出来（这是从原项目里改出来的一处：那边是四个特效一起常开）。
- 手机上粒子数自动减一半左右。
- 想改默认值或加新的一种：`kit.js` 搜 `var MODES =`，`kit.css` 搜 `⑤ 氛围特效`。

### 照片墙

- 打开 `photos.html`：先是一排相册卡片，点进去是照片格子，再点照片是全屏大图（Esc 关掉）。
- 相册地址是 `photos.html#相册id`，所以浏览器后退键能用，地址也能直接发给别人。
- 数据在 `assets/photos.js`。加相册、传图、改封面都在后台的「照片墙」面板里。
- 「传一张照片」需要服务端模式（用 `启动后台.bat` 启动）；双击打开的后台传不了文件。
- 一张照片都没有的空相册不会显示在页面上。

### 一个坑：系统关掉动画时

如果你在 Windows 里关了「动画效果」（设置 → 辅助功能 → 视觉效果），
浏览器会告诉网页 `prefers-reduced-motion: reduce`，**这个站所有动效都会自动停下来**：
逐字标题、上浮、背景网格、小光点、鼠标光晕……全停在静止版，内容照样看得见。

**只有氛围特效例外**——它是"你亲手按开"的，所以照跑。第一次开的时候会提示你一句。

想把动效看全：Windows 设置 → 辅助功能 → 视觉效果 → 打开「动画效果」。

> 本机现在的状态是**关着的**（`MinAnimate = 0`，SPI_GETCLIENTAREAANIMATION = False），
> 所以在这台电脑的浏览器里，站里的动效一直都是静止的。

## 六、在局域网里跑起来（手机看电脑上的站）

双击 **`启动局域网.bat`**（等同于 `node server.js --lan`），终端会打印地址，像这样：

```
  同一个 Wi-Fi 下的手机、平板、别人的电脑，打开这些地址：
      http://192.168.0.103:8787/   ← 一般用这个
```

手机上直接输这个地址就能看你的站；想存书签就存
`http://192.168.0.103:8787/m.html`（手机版）。

### 三种模式

| 命令 | 谁能看网站 | 谁能进后台 |
|---|---|---|
| `node server.js` | 只有这台电脑 | 只有这台电脑 |
| `node server.js --lan` （推荐） | 同一个 Wi-Fi 的所有人 | **只有这台电脑** |
| `node server.js --lan --admin` | 同一个 Wi-Fi 的所有人 | 同一个 Wi-Fi 的所有人（仍要密码） |

### 手机上打不开？挨个试这几个地址

给 Node 单独开一条防火墙规则需要管理员权限，普通账户加不了。
所以 `--lan` 模式下服务会**同时监听几个「系统本来就放行」的端口**，
终端会一次打印出来，手机上挨个试，哪个能通就用哪个：

```
      http://192.168.0.103:8787/    ← 先试这个
      http://192.168.0.103:10246/
      http://192.168.0.103:10247/
      http://192.168.0.103:2177/
```

手机版就是把路径换成 `/m.html`，比如 `http://192.168.0.103:10246/m.html`。

**要记住：电脑上能打开不代表手机能打开**——电脑访问自己的地址走的是内部通道，
不经过防火墙，测不出问题。**必须用手机真正打开一次**。

如果 4 个端口全都不行，那问题就不在电脑这边了，多半是这两个：

1. **手机开着代理 / 加速器**（Clash、各种 VPN、某些浏览器自带的加速）。
   它们会把局域网地址也接管走。关掉代理试试，或者在代理 App 里把
   `192.168.0.0/16`、`10.0.0.0/8` 加进直连规则。
2. **路由器开了「AP 隔离 / 客户端隔离」**——同一个 Wi-Fi 下的设备互相不能访问。
   登录路由器管理页（一般是 192.168.0.1）把这个选项关掉。

### 第一次启动的防火墙弹窗（重要）

Windows 会弹一个窗口问「是否允许 Node.js 访问网络」，
**一定要勾上「专用网络」再点允许**，否则别人的手机打不开。

弹窗没出现、或者当时点了「取消」，用**管理员身份**打开 PowerShell 跑这一条，
直接把端口放行（比在图形界面里翻列表快）：

```powershell
netsh advfirewall firewall add rule name="小窝 8787" dir=in action=allow protocol=TCP localport=8787
```

查有没有加上、或者哪天想撤掉：

```powershell
netsh advfirewall firewall show rule name="小窝 8787"
netsh advfirewall firewall delete rule name="小窝 8787"
```

**怎么判断到底通没通**：电脑上能访问不代表手机能访问——
电脑访问自己的地址走的是内部通道，不经过防火墙。**必须用手机实际打开一次**才算数。

手机一直打不开、又不想动防火墙的话，还有个现成的办法：
你机器上装着 **Radmin VPN**，手机也装一个（应用商店里有）、加入同一个网络，
然后手机访问上面那个 `26.58.122.139:8787` 就行——这条路不受 Windows 防火墙管，
而且不在同一个 Wi-Fi 也能用。

### 别人能改我的东西吗

不能。默认的 `--lan` 模式下我实测过：

- 局域网访问 `/`、`/m.html`、文章页 → **200，正常看**
- 局域网访问 `/admin.html` → **403**，只会看到「这儿只有主人能进」
- 局域网请求 `/api/ping`、`/api/save` → **一律拒绝**，登录和写文件都做不了

另外服务端还加了登录失败锁：同一个 IP 连着错 5 次，锁 2 分钟。

### 几个常见问题

- **手机打不开**：① 确认手机和电脑连的是同一个 Wi-Fi（手机别开流量）；② 检查上面说的防火墙；③ 确认那个黑窗口还开着。
- **地址每次都不一样**：路由器会给电脑换 IP。想固定就在路由器里做「DHCP 静态分配 / 地址保留」，把 `192.168.0.103` 绑给这台电脑。
- **开机自动启动**：按 `Win + R`，输入 `shell:startup`，把 `启动局域网.bat` 的**快捷方式**拖进去（不需要管理员权限）。开机后它会自己跑，但黑窗口会一直在任务栏——关掉它就等于关掉服务。
- **电脑休眠了**：手机就连不上了，去电源设置里把「睡眠」改成「从不」比较省事。

## 七、放到网上

1. 注册 GitHub，新建仓库，名字叫 `你的用户名.github.io`
2. 把 **`index.html`、`m.html`、`posts.html`、`post.html`、`photos.html`、`links.html`、`about.html`、`README.md` 和 `assets` 文件夹**拖上去
   （`admin.html`、`server.js`、`启动后台.bat` 是给自己用的，**别传**）
3. 等一两分钟，访问 `https://你的用户名.github.io`

本地给别人看（同一个 Wi-Fi）：

```bash
python -m http.server 8000
```

## 八、小提示

- 手机上打开会自动变单栏。
- 右上角圆按钮切白天/夜间，选择记在浏览器里。
- 服务端那个黑窗口关掉，后台就用不了了（网站本身照常能看）。
- `posts.js.bak` / `site-data.js.bak` / `photos.js.bak` 是上一版备份，出错了可以把 `.bak` 去掉后缀换回来。
- 后加的几个功能都在 `assets/kit.js` / `kit.css` 里，不动 `style.css` 和 `site.js` 也能单独删掉。
